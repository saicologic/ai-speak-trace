# コードベース調査

`$ARGUMENTS` について徹底的に調査する。

## 調査手順

1. Glob と Grep で関連ファイルを検索
2. 関連コードを読み込んで分析
3. 依存関係やデータフローを追跡
4. 調査結果をまとめる

## 報告形式

以下の形式で日本語で報告する:

1. **概要**: 調査トピックの全体像
2. **関連ファイル**: ファイルパスと役割の一覧
3. **実装の詳細**: コードの動作や設計パターン
4. **依存関係**: 他のモジュールとの関係
5. **注意点**: 改善の余地やリスクがあれば記載
