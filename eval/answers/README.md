# 相手の質問の取り出し（実験用）

質問される側（面談・面接・インタビューを受ける側）の会話から、相手の質問を取り出し、
自分の答えと組にする手法を比べる実験用のプロジェクト。
ディープサーチで「答えの確かめ」（自分の答えを、自分の資料・面接で見られる点・Web と照らし合わせる）を
作るための最初の段階。**ここではアプリは変えない。**

- uv で、`eval/answers/` だけの独立したプロジェクトにしている（Python 3.12）
- 有料の API は使わない
- 実データ（`.data/`）と実行結果（`results/`）はコミットしない（`eval/answers/.gitignore`）

## 準備

```sh
cd eval/answers
uv sync
uv run pytest
```

## 1. データをコピーする

アプリの文字起こしのフォルダと、質問される側（自分）の話者IDを渡す。

```sh
uv run python scripts/copy_data.py "<文字起こしのフォルダ>" --self speaker_0
```

話者・発話だけを `.data/conversation.json` にコピーする。アプリのデータには書き込まない。

## 2. 正解を作る

```sh
uv run python scripts/make_sentences.py
```

相手の文を1行ずつ `.data/sentences.tsv` に書き出す（`.data/gold.tsv` があれば判定を引き継ぐ）。
`label` に 1（自分への質問）か 0 をつけ、`.data/gold.tsv` として保存する。

### 正解の基準

- 1 にする：自分に答えや確認を求める文。「〜みたいな感じで。」のように疑問の形でなくても、
  確認として自分が答えているものは 1。言い切らない質問（「何か確認しておきたいこととかは。」）も 1
- 0 にする：あいづち・お礼・説明、相手の答えの言い返し（「働いてる場所。」）、説明の中の引用や「？」
- 1つの質問が話者の切り替わりで2つの発話に分かれたときは、後ろの発話の文を 1 にする

## 3. 実行する

```sh
uv run python scripts/run_eval.py
```

`results/<日時>/report.md` に比べた表と、手法ごとの取りこぼし・誤りを保存する。

## 比べる手法

| 手法 | 中身 |
|------|------|
| 1. 疑問符だけ | 文字起こしがつけた「？」で終わる文 |
| 2. 疑問符 + 言い回しの規則 | 「〜ますか。」「いかがですか。」「〜って感じですかね。」「〜って感じで。」などの文末 |
| 3. 2 + 自分の返事 | 相手の発話の最後の文で、次の自分の発話が「はい」「そうです」などで始まるもの（あいづち・お礼は除く） |
| 4. SudachiPy の品詞 + 自分の返事 | 文末の終助詞「か」など、疑問詞を含み名詞・助詞で終わる文 |
| 5. すべての和 | 2・3・4 のどれかで質問とした文 |

## 比べ方

- 文：質問の文の適合率・再現率・F1
- 発話：質問を含む発話を見つけられたかの適合率・再現率・F1
- 答えの一致：質問を含む相手の発話から、次の質問の発話までの自分の発話を答えとする。
  正解の質問のうち、答えの範囲が正解と同じになった割合（質問の取りこぼしや誤りで、答えの範囲がずれる）
