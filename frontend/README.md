# AI Speak Trace - Frontend

音声データの文字起こし結果の閲覧・キーワード抽出・会話分析を行うフロントエンドアプリケーションです。

## 主な機能

- **入力**: 音声ファイル（mp3, m4a, wav など）のアップロード
- **文字起こし**: AIによる話者分離の実行・結果表示
- **出力**: キーワード抽出 & フィルター、話者ごとの色分け表示
- **深掘り**: キーワードから調査質問を生成し、Web検索付き分析レポートを表示
- **設定**: APIキー管理、ベータ機能の有効化

## セットアップ

### 依存パッケージのインストール

```bash
npm install
```

### 環境変数

開発時はViteのプロキシ設定により `http://localhost:3100` へ自動的に転送されるため、環境変数の設定は不要です。

本番環境ではバックエンドのURLを指定してください。

```env
VITE_API_BASE_URL=https://your-backend-url.com/api
```

### 開発サーバーの起動

```bash
npm run dev
```

http://localhost:5173 でアクセスできます。

### ビルド

```bash
npm run build
```

ビルド結果は `dist/` に出力されます。

## テスト

### ユニットテスト

ユーティリティ関数のテストを vitest で実行しています。テストファイルは対象ファイルと同階層に `.test.ts` として配置しています。

| テストファイル | テスト対象 | 内容 |
|--------------|-----------|------|
| `utils/keywords.test.ts` | `extractKeywords` | 専門用語・固有名詞のキーワード抽出ロジック |

### テスト実行

```bash
# ユニットテスト（1回実行）
npm run test:run

# ウォッチモード（ファイル変更時に自動実行）
npm run test
```

### その他のコマンド

```bash
# ビルド結果のプレビュー
npm run preview

# リント
npm run lint
```
