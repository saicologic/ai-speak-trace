# 使い方

[README に戻る](../../README.md)

## 1. ファイルアップロード・文字起こし・結果確認

1. 左サイドバーの「音声ファイルの文字起こし」をクリックする
2. 音声ファイルを選択し、クレジット残量を確認する
3. 録音されている全員の同意を得ていること（または一般に公開されている音声であること）を確かめ、同意のチェックを入れる。チェックを入れるまで文字起こしは実行できません
4. 「文字起こしを実行」をクリックする。完了すると、メイン画面に話者ごとに色分けされた文字起こし結果が表示されます
5. 音声を再生・停止し、🔍ボタンで現在の再生位置に該当する発話へ自動スクロールする
6. 発話のタイムスタンプや単語をクリックすると、その位置から音声を再生します

文字起こしが途中で止まった場合は、左サイドバーの「中断中のジョブ」から対象のジョブを選び、「途中から再開する」をクリックします。完了済みのチャンクはスキップされます。

## 2. 話者フィルター

1. 右サイドバーの「話者フィルター」で話者を選択する
2. その話者の発話だけに絞り込んで表示し、キーワード一覧もその話者の発話から抽出したものに切り替わります（「全員」に戻すと会話全体のキーワードに戻ります）
3. フィルター中に発話をクリックすると、直前の別話者の発話をポップアップで表示します

## 3. キーワードフィルター

1. 右サイドバーに、専門用語・固有名詞を自動抽出したキーワード一覧が表示されます（「キーワードを検索」で一覧を絞り込めます）
2. キーワードをクリックすると、ハイライト表示します
3. 「フィルター」ボタンで、選択したキーワードを含む発話だけに絞り込む
4. 設定画面の「キーワード」で「GiNZA のキーワード抽出」を有効にすると、一覧の上で「標準」と「GiNZA」を切り替えられます（下の「ベータ版の機能」を参照）

## 4. 要約

「AI 分析を使う」が ON で、設定が済んでいる場合に使えます（以下の 5〜7 も同じ）。Claude に送るときは、個人情報チェックで「伏せる」を選んだ文字列を置き換えます（下の「個人情報チェック」を参照）。

1. 右サイドバーの「要約」ボタンで要約ページを開く
2. モデルを選び、必要なら「概要」「キーポイント」「決定事項」の指示を書き換える（「Claudeへのインプット」で送る内容を確認できます）
3. 「要約する」で実行し、完了したら「要約結果を見る」で表示する。過去の要約は「要約結果」から開けます

## 5. 会話分析

1. 「会話分析」ボタンで会話分析ページを開く
2. 話者を選択すると、その話者のキーワードが表示されます（GiNZA のキーワード抽出が有効な場合は「標準」と「GiNZA」を切り替えられます）
3. キーワードを選択して「質問を生成」→ チェックボックスで質問を選択 →「分析する」で実行する
4. [Claude API](https://docs.anthropic.com/ja/docs/welcome)が Web検索付きの分析レポートを生成し、出典URLも表示します

## 6. ディープサーチ

会話に出てきた用語を、Web の公式情報で詳しく調べて解説します。

1. 左サイドバーの「ディープサーチ」を開き、「① 調べる会話を選ぶ」で会話を選ぶ（前編・後編のように、関連する会話をまとめて選べます）
2. 会話ごとの「個人情報チェック」で、Claude に送る前に伏せる文字列を確認する（下の「個人情報チェック」を参照）
3. AI が調べるべきキーワードと公式サイトを提案するので、「② 調べるキーワードと公式サイトを確定する」で選んで確定する
4. 公式サイトを先に調べ、足りなければ一般のサイトも調べて、[Claude API](https://docs.anthropic.com/ja/docs/welcome)がキーワードごとに解説します
5. 根拠を確認できなかった文は表示から除き、「この調査の記録」に理由と一緒に残します。過去の調査は「調査結果」から開けます

仕組みは[ディープサーチの設計](../developers/deep-search.md)を参照してください。

## 7. 発言の文脈

1. 右サイドバーの「発言の文脈」を押し、文字起こし結果から発言を複数選択する
2. 選んだ発言の意図・トピックを、[Claude API](https://docs.anthropic.com/ja/docs/welcome)が解析します

## 8. 個人情報チェック

Amazon Bedrock Guardrails で会話に含まれる個人情報を検出し、Claude に送る前に伏せます。

- 伏せる文字列を選ぶ画面は、ディープサーチの「① 調べる会話を選ぶ」で会話を選んだときに表示されます。ここで選んだ結果は、ディープサーチ・要約・会話分析で使われます
- 電話番号・メールアドレスなどは、最初から伏せます。ディープサーチで選んだことのない会話でも、Claude に送るときに自動で伏せます
- 氏名・住所などは、製品名や国名も検出されるため「要確認」とし、「伏せる」を選ぶまでは伏せずに送ります
- 「伏せる」を選んだ文字列は、Claude に送るときに `[氏名]` のように置き換えます。元の文字起こしは変わりません

送るデータと保存先の詳細は [PRIVACY.md](../../PRIVACY.md) を確認してください。

## 9. 誤りを報告

要約・会話分析・発言の文脈・ディープサーチの結果には「誤りを報告」ボタンがあります。報告はこの Mac にだけ保存し、外部には送りません。結果を見直すときに、報告した内容を一緒に表示します。

## 10. ベータ版の機能

設定画面の「キーワード」から有効にできます（最初は無効）。AWS も Claude も使いません。

**GiNZA のキーワード抽出**

- 右サイドバーのキーワード一覧と会話分析で、キーワードの抽出方法を「標準」と「GiNZA」で切り替えられます。選んだ方法は会話ごとに保存します
  - 標準: カタカナ語・英字の語を正規表現で抽出します
  - GiNZA: 日本語を解析する[GiNZA](https://megagonlabs.github.io/ginza/)で名詞のまとまりを取り出します。標準では取れない漢字だけの語（評価・型チェックなど）も抽出できます。回数の多い順に並べ、人名・すべての会話に出てくる語・会話によく出てくる一般的な語は除きます
- 漢字の語が中心の会話では GiNZA、カタカナ語・英字の語が中心の会話（技術系の Podcast など）では標準が見やすいことが多いです
- 初めて「GiNZA」を選んだときに「GiNZA を入れる」を押すと、Python 3.12 と GiNZA（約 500MB）をダウンロードして `~/Library/Application Support/io.github.saicologic.ai-speak-trace/ginza/` に入れます（1分ほどかかります）。DMG には含まれません
- 解析はこの Mac の中で行い、会話を外部に送りません。macOS（Apple シリコン）で動作確認しています

## データの保存先

文字起こし結果や音声ファイルは、`~/Library/Application Support/io.github.saicologic.ai-speak-trace/data/` に保存します（設定画面の「データ保存先」の「フォルダを表示」で開けます）。フォルダごとの内容と削除方法は、[PRIVACY.md](../../PRIVACY.md) の「端末に保存するデータ」と「データの削除」を確認してください。
